# Local agent entry point

For requests to queue remote work in trajectory or dd-trace-py, read `skills/queue-project-task/SKILL.md`.
That skill creates a managed Jira task through Atlassian MCP.
For requests to implement this automation itself, work in this repository directly.

For requests to explain unfamiliar code through a guided walkthrough, read
`skills/explain-code/SKILL.md`. The Code Walk UI and bundler live in
`agentic_louis/code_walk.py` and `agentic_louis/code_walk_web/`.
